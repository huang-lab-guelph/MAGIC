Sparky GUI Plugins (Python 2.7 Only - Not Maintained)
======================================================

These files are NMRFAM-Sparky GUI plugins that require Python 2.7
and the Sparky environment to function. They have NOT been migrated
to Python 3 as part of the MAGIC codebase modernization.

Files:
- MAGIC_Act.py: Sparky plugin for interactive MAGIC assignment
- MAGIC_View.py: Sparky plugin for visualization of MAGIC results

If you need Sparky GUI functionality, you must use:
- Python 2.7
- NMRFAM-Sparky distribution
- Original Python 2.7 versions of the MAGIC core files

The core MAGIC algorithm and utilities have been successfully
migrated to Python 3.13 and are fully functional without these
GUI plugins.
